# Vexon Security Scanner 2.0

Εφαρμογή Windows για εξουσιοδοτημένο έλεγχο ιστοσελίδων, με ελληνικό GUI, πελάτες/έργα, ιστορικό, επανέλεγχο και αναφορές PDF.

## Χρήση

1. Εγκατάσταση από το ZIP του τελευταίου επιτυχημένου **Build Windows EXE** στα GitHub Actions. Περιέχει `Vexon-Security-Scanner-Setup-2.0.0-x64.exe`.
2. **Νέα ιστοσελίδα**: όνομα έργου, πελάτης, URL, προαιρετικό `owner/repository`, επιλογές ελέγχου και επιβεβαίωση άδειας.
3. **Σάρωση** και κατόπιν **Αναφορά** για αποδείξεις, URL, σοβαρότητα, τύπο ευρήματος και ενέργεια διόρθωσης.
4. **Έλεγχος ξανά** συγκρίνει με την προηγούμενη σάρωση. «Διορθώθηκε» σημαίνει ότι ο συγκεκριμένος έλεγχος επαναλήφθηκε και το εύρημα έλειπε. Οι μη ελεγμένες περιοχές παραμένουν «χρειάζεται επιβεβαίωση».
5. **Λήψη PDF / JSON**. Επωνυμία, στοιχεία επικοινωνίας και λογότυπο ορίζονται στις Ρυθμίσεις.

## Τι ελέγχεται

- HTTP/TLS: έως 20 σελίδες, πιστοποιητικό, λήξη, security headers, cookie flags, mixed content, SRI και μη κρυπτογραφημένες φόρμες.
- Chromium: έως 3 επιτυχώς ελεγμένες σελίδες με JavaScript, console errors, αποτυχημένα requests και HTTP errors. Απομονωμένο προσωρινό session χωρίς λογαριασμούς χρήστη, permissions, POST, downloads ή νέα παράθυρα. Αποθηκεύονται τοποθεσίες console errors και όχι το πλήρες μήνυμα, για προστασία δεδομένων.
- GitHub: snapshot του default branch σε συγκεκριμένο commit, έως 60 επιλεγμένα αρχεία ≤2 MB. Κανόνες για πιθανά API keys, private keys, debug, eval και απενεργοποιημένη επαλήθευση TLS. Πρόκειται για στατικούς ελέγχους με ανάγκη ανθρώπινης επιβεβαίωσης, όχι πλήρες SAST.
- Εξαρτήσεις: έως 300 μοναδικές ακριβείς npm εκδόσεις από `package-lock.json`, αναζήτηση γνωστών αναφορών στο OSV. Δεν εκτελείται ο κώδικας του repository και δεν εγκαθίστανται οι εξαρτήσεις του. Άλλα οικοσυστήματα και unfixed ranges δεν καλύπτονται.

Δημόσια GitHub repos λειτουργούν χωρίς token, εντός ορίων GitHub API. Για ιδιωτικά repos χρησιμοποιείται δικό σου fine-grained token με Contents: Read για τα συγκεκριμένα repos. GitHub API failures και όρια καταγράφονται ως μερική κάλυψη.

## Προγραμματισμός και ειδοποιήσεις

Ανά ιστοσελίδα: χειροκίνητα, κάθε 24 ώρες ή κάθε 7 ημέρες. Ο scheduler ελέγχει κάθε λεπτό, εκτελεί μία σάρωση κάθε φορά και ανακτά εκκρεμείς ελέγχους μετά από επανεκκίνηση. Μια χειροκίνητη σάρωση δεν αλλάζει το πρόγραμμα.

Το παράθυρο κλείνει στο tray. **Έξοδος** από το tray τερματίζει την εφαρμογή και τον scheduler. Προαιρετική εκκίνηση με Windows από τις Ρυθμίσεις (στην εγκατεστημένη έκδοση). Δεν είναι Windows service και δεν εκτελείται όταν ο υπολογιστής είναι κλειστός/σε αναστολή. Ειδοποιήσεις για scheduled runs, νέα ευρήματα και λήξη πιστοποιητικού μέσα σε 30 ημέρες, κατά τη σάρωση. Τα Windows/Focus Assist μπορεί να αποκρύπτουν ειδοποιήσεις.

## OpenRouter

Παραμένει η αυτόματη επιλογή επιβεβαιωμένων zero-price μοντέλων και fallback σε rate limits/timeouts, χωρίς πίνακα AI. Χρειάζεται API key και ενεργοποίηση ανά έργο. Στέλνεται μόνο αποπροσωποποιημένη περίληψη ευρημάτων, όχι κώδικας ή cookie values. Στο OSV αποστέλλονται μόνο ονόματα και εκδόσεις πακέτων. Η AI δεν μεταβάλλει ευρήματα ή χαρακτηρισμό επίλυσης.

Τα δωρεάν μοντέλα έχουν όρια. Η εξάντληση του συνολικού ορίου λογαριασμού δεν παρακάμπτεται. Η τεχνική αναφορά διατηρείται όταν η AI δεν απαντά.

## Αξιοπιστία και δεδομένα

Αποτυχημένες, ακυρωμένες και μερικές σαρώσεις **δεν λαμβάνουν βαθμολογία**. Η βαθμολογία πλήρους σάρωσης είναι ενδεικτική ρυθμίσεων και δεν πιστοποιεί ασφάλεια. Τα ευρήματα διαχωρίζονται σε παρατηρήσεις, συστάσεις και πιθανά προβλήματα.

Τα credentials αποθηκεύονται με Electron safeStorage / Windows DPAPI και διατηρούνται όταν αφήνεις τα πεδία κενά. Ιστορικό και ρυθμίσεις: Electron userData, υποφάκελος `reports/` και `workspace-v2.json`. Τα reports είναι τοπικά JSON. Κράτησε αντίγραφο του userData για μεταφορά/backup. Κάθε PDF διατηρεί τα στοιχεία έργου όπως ήταν κατά τη σάρωση.

Οι HTTP συνδέσεις και ο proxy του Chromium ελέγχουν δημόσιες IP και συνδέονται στη συγκεκριμένη ελεγμένη IP. Μπλοκάρονται loopback, private, link-local, reserved και IPv4-mapped private IPv6. Μόνο HTTP/HTTPS στις θύρες 80/443. Το read-only browser profile μπορεί να μπλοκάρει λειτουργίες ιστοσελίδων· αυτό δηλώνεται στην κάλυψη.

## Ανάπτυξη και build

Node 22 ή νεότερο:

```sh
npm ci
npm test
npm start
npm run test:desktop
npm run build:win
```

Το Windows workflow τρέχει unit tests, πραγματικό Electron smoke test (preload/IPC, αποθήκευση, ιστορικό, αποτυχημένο scan, UI, PDF) και μετά δημιουργεί unsigned NSIS installer. Το Chromium περιλαμβάνεται στον installer. Δεν απαιτείται εγκατάσταση Python, Node ή browser στον τελικό υπολογιστή.

Η εφαρμογή δεν εκτελεί exploits, brute-force, authenticated scans ή πλήρες penetration test. Τα Windows μπορεί να εμφανίσουν SmartScreen επειδή δεν υπάρχει πιστοποιητικό code signing.
